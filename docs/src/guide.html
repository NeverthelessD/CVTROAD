START처음 한 번만 5분이면 끝나요

1

압축 풀고 옮기기

CVTROAD.zip을 풀고 CVTROAD를 응용 프로그램 폴더로 옮겨요. 그래야 자동 업데이트가 돼요.

2

보안 허용

처음 열 때 경고가 뜨면 시스템 설정 → 개인정보 보호 및 보안 맨 아래에서 “그래도 열기”를 눌러요.

3

변환 엔진은 알아서

처음 켜면 영상·오디오용 변환 엔진(약 90MB)을 한 번만 받아요. 이미지·문서·PDF는 바로 돼요.

4

도우미 알림은 괜찮아요

‘백그라운드 항목이 추가됨’ 알림은 CVTROAD 도우미예요. 켜 두면 앱을 열지 않아도 바꿀 수 있어요.

ROUTE바꾸는 다섯 가지 길 편한 걸 골라 쓰세요

⇧+끌기

Shift-드래그

Finder·바탕 화면에서 파일을 끌다가 Shift를 누르면 커서 주변에 원형 메뉴가 떠요. 표지판 위에서 손을 떼면 끝, 가운데에서 떼면 취소. ⇧+⌥은 도구 메뉴.

⌃⌥C

단축키

Finder에서 파일을 고르고 ⌃⌥C(변환) · ⌃⌥T(도구). 마우스, 방향키 + Enter, 숫자로 골라요. Esc는 취소.

오른쪽 클릭

빠른 동작

파일을 오른쪽 클릭 → 빠른 동작 → CVTROAD → JPG / PDF / MP3로 바꾸기. 고르지 않고 바로 바뀌어요.

메뉴 막대떠 있는 창

위젯처럼

메뉴 막대 아이콘에서 잠시 멈추기·앱 열기. 떠 있는 변환 창을 켜면 화면 구석 표지판에 파일을 놓기만 하면 돼요.

앱 창

앱에서 자세히

파일·폴더를 창에 끌어다 놓고 → 오른쪽 표지판(형식) 또는 도구를 고르고 → 바꾸기. 화질·음질도 여기서 골라요.

EXIT어디로 바꿀 수 있나요 초록 = 형식 바꾸기 · 파랑 = 도구

앱 사용법 화면 위쪽 탭

변환파일을 넣으면 바꿀 수 있는 형식만 표지판으로 보여요. 여러 개·여러 종류를 한꺼번에 넣어도 돼요.
도구형식은 그대로 두고 손보기 — 용량 줄이기, 정보 지우기, PDF 나누기·합치기·페이지 정리.
도우미원형 메뉴를 미리 체험하고, 도우미·떠 있는 창·빠른 동작을 켜고 꺼요.
설정화면 모드(시스템 · 라이트 · 다크), 저장할 곳(원본 옆 / 기본 폴더), 기본 화질·음질.
작업진행률이 보이고 언제든 멈출 수 있어요. 끝나면 Finder에서 보기 · 열기.
업데이트오른쪽 위 v1.0.0 이 지금 버전. 새 버전이 나오면 앱이 알아서 받아요. 바로 확인하려면 설정 → 업데이트 확인.

⚠️ 알아두면 좋은 점

  • 🛡️원본은 바뀌지 않아요. 새 파일을 원본 옆에 만들고, 같은 이름이 있으면 “(2)”를 붙여요.
  • 🔒파일은 어디에도 보내지 않아요. 인터넷은 변환 엔진을 처음 받을 때와 업데이트할 때만 써요.
  • 📂위치를 알 수 없는 파일(다른 앱·브라우저에서 끌어온 파일)은 기본 폴더(처음엔 다운로드)에 저장돼요.
  • 📄PDF → 글자는 글자만 꺼내요. 사진으로 찍은(스캔한) PDF는 글자가 나오지 않을 수 있어요. 문서 변환은 서식이 조금 달라질 수 있어요.
  • ⏱️큰 영상은 시간이 걸려요. 창을 닫아도 작업은 계속되고, 끝나면 알림으로 알려 줘요.
  • 🔔아이폰 벨소리(M4R)는 40초까지라서 앞 40초만 담아요.
